# Challenge-17-BFS-DFS
A C program that represents a file system as a graph using an adjacency matrix and implements Breadth-First Search (BFS) and Depth-First Search (DFS) to search for files and display traversal order.
Challenge 17 – File System Representation and Search Using BFS and DFS

Objective

To represent a file system as a graph using an adjacency matrix and search for files using Breadth-First Search (BFS) and Depth-First Search (DFS).

Technologies Used

- Programming Language: C
- Data Structure: Adjacency Matrix
- Algorithms: BFS and DFS

Features

- Represents files and directories as graph nodes.
- Stores connections using an adjacency matrix.
- Displays BFS and DFS traversal orders.
- Checks whether the target file is found.

Files

- "main.c" – C source code.
- "sample_output.txt" – Sample input and expected output.

How to Run

Compile the program using a C compiler:

"gcc main.c -o main"

Run it:

"./main"

On Windows, run "main.exe" after compiling.

Result

The program demonstrates graph traversal using BFS and DFS to search for a specified file or directory.
